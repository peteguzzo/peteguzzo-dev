### SECTION 2: THE FOUR LEVELS (Core Analogy)

**Purpose:** Establish the conceptual framework in a visceral, memorable way.
**Visual treatment:** This is the flagship designed section. NOT a bullet list. A PROGRESSION — you feel each level as you scroll. Dark/moody aesthetic. Each level gets its own visual weight. The transition from Level 3 to Level 4 should feel like a gear shift.

**Content framework (from briefing — verified against CORTEX source):**

LEVEL 1 — MANUAL
You tell the agent what to do. It does it. It forgets everything. Next session: start over.

LEVEL 2 — VIDEO
You give the agent documentation. It reads it. Better than nothing. But documentation doesn't capture what went wrong last Tuesday or why the thing that should work doesn't.

LEVEL 3 — EXPERT HANDOFF NOTES
Before a session ends, you write down what happened. The next agent reads it. Real improvement. But you're writing the notes, and the notes are only as good as what you remembered to include.

LEVEL 4 — CORTEX (The system that stays)
An experienced supervisor who never leaves. Accumulates verified experience across every session. Knows what broke and why. Knows what the last agent tried and what worked. Gives the next agent a real baseline instead of zero. Not because it was told to — because it learned to.

"The organization should not have to pay for the same mistake twice."
"Previous mistakes no longer need to be rediscovered."

**Visual execution:** Each level gets a row with increasing complexity/visual weight. Level 4 breaks the pattern — different color, different layout, different energy.
