# REFLEX_RULES

Generalized lessons promoted from verified incidents. Applied automatically at `/cortex-start` and `/cortex-recover`.

Rules:
- Only promote a lesson here when it is supported by verified evidence from a specific incident.
- Never promote a theory or assumption.
- Each rule must be actionable and falsifiable: it states what to do when a specific detectable condition is present.
- Cross-reference the originating incident.

---

## How to use this file

At `/cortex-start`: scan for rules matching the current task.
At `/cortex-recover`: scan for rules matching the current symptom.
Apply matching rules before taking any action.
